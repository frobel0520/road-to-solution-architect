## 2. 已確認的決定（2026-11-08）

1. 沿用本 repo 改方向，不另開新專案。網站骨架、部署、進度儲存、決策題機制都保留；只重寫課程定位、課綱與內容。

3. 深度是**概念＋何時用**：講是什麼、解決什麼問題、和替代方案怎麼選；仍然不寫程式。

## 4. 新課綱（2026-11-08 核准）

每個單元固定回答四件事：**它是什麼**、**沒有它會怎樣**、**有哪些替代方案、怎麼選**、**一題情境決策題**。

### 模組 0　導論（2 單元）

- 一個網站從輸入網址到看到畫面，經過哪些技術（全課地圖）
- 怎麼讀這門課：術語、圖例、決策題

### Web 與網路基礎

**模組 1　網路基礎（5 單元）**

- IP、port 與封包：電腦怎麼找到彼此
- TCP 與 UDP：可靠與即時的取捨
- DNS：網址怎麼變成 IP
- HTTP 與 HTTPS（TLS）：請求、回應與加密
- CDN、反向代理與負載平衡

**模組 2　前端與瀏覽器（5 單元）**

- 瀏覽器怎麼把 HTML、CSS、JavaScript 變成畫面
- 靜態網站、SPA、SSR：三種網站做法怎麼選
- Cookie、Session、localStorage：資料存在哪
- 同源政策與 CORS
- 前端效能：載入速度從哪裡來

**模組 3　API 與系統溝通（5 單元）**

- API 是什麼：系統之間的合約
- REST 與 JSON
- GraphQL、gRPC：什麼時候不用 REST
- Webhook、WebSocket、SSE：誰主動通知誰
- API 的錯誤、版本與限流

### 資料與後端

**模組 4　後端基礎（4 單元）**

- 伺服器、runtime 與框架在做什麼
- 單體、微服務、Serverless
- 同步與非同步處理
- 登入背後：認證與授權的差別

**模組 5　資料庫（5 單元）**

- 關聯式資料庫與 SQL 在做什麼
- NoSQL 的四種類型與適用情境
- 索引：為什麼查詢會變快
- 交易與 ACID
- 正規化、反正規化與 ORM

**模組 6　擴展與效能（4 單元）**

- 快取：Redis 與 CDN 快取
- 訊息佇列與事件
- 複寫、讀寫分離與分片
- CAP 與一致性：分散式系統的取捨

合計 6 模組加導論、30 單元。
