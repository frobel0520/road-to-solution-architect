依 `docs/03-system-design.md` 第 6 節。CR-001 改版後的新模組 0、1，共 7 個單元（全部 draft）。這份只有**本機**結果，正式網址在部署後另外量。

## 結果

| 指標 | 門檻 | 結果 | 判定 |
|---|---|---|---|

| 單元頁 JavaScript（gzip） | ≤ 30 KB | 3.0 KB | 通過 |
| LCP（手機）p95 | ≤ 2.5 秒 | 首頁 p50 1,207／p95 1,359 ms；模組頁 1,207／1,359 ms；單元頁 1,055／1,057 ms | 本機通過；正式環境待驗收 |

| TBT p95 | ≤ 200 ms | 三頁都是 0 ms | 本機通過；正式環境待驗收 |
| 決策題作答回饋 p95 | ≤ 100 ms | E2E `quiz-latency.spec.ts` 通過（fixture 內容）；前端程式沒變 | 本機通過；正式環境待驗收 |

- 受測頁：首頁 `/`、模組頁 `/modules/m01/`、單元頁 `/units/m01-u03/`，各 10 次。
- 傳輸量：`node scripts/check-budget.ts dist --json docs/evidence/bundle-20261108-m00-m01-tech.json`。
- Lighthouse：`node scripts/perf-lighthouse.mjs http://localhost:4322 docs/evidence/lighthouse-20261108-local.json 10`，每次的樣本都在 JSON 裡。
- 本機沒有網路延遲，LCP 主要反映節流後的渲染時間，不能代表正式網址。
